Executive Summary

An exhaustive statistical and pipeline audit was performed on the Kloudtrack multi-horizon prediction engine (horizons: 1h, 3h, 6h, 12h, 24h, 48h, 72h). Priority was placed on rigorous, out-of-sample physical predictive fidelity.

Key Findings Summary:
  • The Horizon Offset Bug: In prior benchmark exports, errors were computed as pred(t+1h) - actual(t) instead of pred(t+1h) - actual(t+1h). Predictions for 3h–72h were unjoined. This created an illusion of low 1h error and non-monotonic long-horizon errors.
  • The "81.95% Rain Accuracy" Artifact: Caused by majority-class collapse. Applying an uncalibrated 0.50 threshold on an 18% base rain rate led the model to predict "NO RAIN" 100% of the time at 1h, missing all 739 true rain events (Recall = 0.00%). Persistence achieved F1 = 0.730 and 91.3% accuracy.
  • Hardware Outlier Contamination: Barretto AWS suffered thermistor failure (transmitting 105.69°C–130.00°C), while Doña Maria AWS experienced 2,319 barometric dropouts (666.9 hPa–780.4 hPa). Unfiltered ingestion caused catastrophic model errors (>85°C).
  • Hydrologic Discharge Over-Decay: Forced exponential decay towards 3.44m caused a massive 0.518m error at 24h for water levels. A hydrologic inertia model reduced this error to 0.062m (88% reduction).
  • Processed Telemetry Equaled Raw Telemetry: 100.00% identical across all populated variables. It did not represent an independent validation source.

  • Horizon 1h: ECE = 0.0953, Brier Score = 0.0682
  • Horizon 6h: ECE = 0.1122, Brier Score = 0.1340
  • Horizon 24h: ECE = 0.1025, Brier Score = 0.1412
  • Calibrated Threshold: Deriving an asymmetric threshold (p = 0.24) lifts 1h recall from 0.00 to 0.731 and 24h recall from 0.569 to 0.787.
  • Prediction Interval Coverage: 80% Temperature PI covers 81.4% (width: ±1.84°C); 95% Water Level PI covers 96.8% (width: ±0.18m).

9. Answers to Primary Questions

  1. Is the current benchmark valid?
    Partially. The raw telemetry from active stations is authentic. However, the prior benchmark export methodology was invalid due to origin-time subtraction and unflagged sensor hardware spikes (130°C, 666 hPa). The corrected dataset Kloudtrack_Corrected_Audited_Benchmark_2026-09-01_to_2026-09-20.csv establishes full validity.
  2. Is there evidence of data leakage?
    No future target leakage was found in the model features, but there was an evaluation alignment bug: predictions were evaluated against origin time t rather than target time t+h. The "81.95% rain accuracy" was a majority-class collapse where the model predicted "NO RAIN" unconditionally, missing all rain events.
  3. Which forecast horizons are currently reliable?
    Water Level: 1h to 24h are highly reliable (MAE < 0.10 m) using hydrologic inertia. Temperature: 1h, 3h, and 24h are reliable (MAE 0.62°C–1.15°C); 6h and 12h require the diurnal solar cycle correction (MAE 2.13°C–2.21°C). Rain State: 1h to 6h are operationally reliable (F1 = 0.53–0.73, Recall = 68%–73%). 12h to 72h should be treated as probabilistic indicators.
  4. Which model changes should be implemented first?
    (1) Remove forced exponential river discharge decay and adopt hydrologic inertia.
    (2) Adopt calibrated operational rain threshold p = 0.24 with Platt scaling.
    (3) Deploy physical ingestion validation bounds (10°C ≤ T ≤ 45°C, 940 hPa ≤ P ≤ 1040 hPa).
    (4) Deploy horizon-specific hybrid model routing.
  5. What additional data is needed before production deployment?
    (1) Doppler radar reflectivity grids (crucial for rain event tracking beyond 3 hours).
    (2) Upstream Angat and Pantabangan reservoir release telemetry.
    (3) Hardware sensor health telemetry (battery voltage, RSSI, transducer status).
